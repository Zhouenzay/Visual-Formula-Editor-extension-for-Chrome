Chrome浏览器的公式编辑器插件VFE 3.0 Release

支持在Chrome浏览器（以及使用Chrome内核的浏览器，如Microsoft Edge，ChatGPT Atlas等）中以可视化方式编辑数学公式，并自动转化成latex代码

功能包括：  
1.常用数学公式的编辑，如分数、根号、上下标等  
2.行列式，微积分，求和，求积等  
3.编辑内容自动保存，并在下次打开时恢复

VFE 3.0 Release, a formula editor plugin for Chrome (core) browsers that converts viusal formulas to latex code.  

Features include:  
1. Editing common mathematical formulas, such as fractions, square roots, subscripts, and superscripts.
2. Determinants, calculus, summation, and product calculations.
3. Automatic saving of edits, which are restored upon next opening.
